# MatchPoint 🎾

MatchPoint es una página web diseñada para consultar y organizar torneos de pádel de manera simple e intuitiva.

El proyecto permite explorar torneos disponibles y crear torneos propios, gestionando participantes, formatos de competencia, cruces y resultados.

## Descripción

**MatchPoint** fue desarrollado como proyecto de la materia **Taller de Desarrollo Web**. 

El objetivo del sitio es facilitar la organización de torneos de pádel entre amigos y permitir la consulta de torneos publicados. La página permite organizar un torneo propio, registrar los resultados de cada partido y generar automáticamente las siguientes instancias y cruces según los resultados obtenidos.

Además, actualmente la información sobre torneos de pádel suele encontrarse dispersa en diferentes sitios o plataformas. Por este motivo, MatchPoint busca reunir la información de distintos torneos en un solo lugar, facilitando que los usuarios puedan encontrar un torneo cuando lo necesiten y según la ubicación que les resulte conveniente sin tener que andar investigando por distintos medios.

La página fue desarrollada utilizando **HTML, CSS y JavaScript**, sin utilizar base de datos ni sistema de inicio de sesión.

## Funcionalidades

Entre las principales funcionalidades del proyecto se encuentran:

- Visualización de torneos publicados.
- Búsqueda de torneos por nombre.
- Filtrado de torneos por fecha, nivel y ubicación.
- Visualización de información detallada de cada torneo.
- Creación y organización de un torneo.
- Carga de parejas participantes.
- Selección del nivel del torneo.
- Selección del formato de competencia.
- Generación automática de partidos.
- Carga y validación de resultados.
- Avance automático entre las diferentes fases.
- Visualización del campeón y resultados finales.

## Páginas del sitio

### Inicio

Presenta **MatchPoint**, sus principales características y una introducción al funcionamiento de la plataforma. Se explica cómo funciona la organización de torneos y, además, se muestran los torneos más destacados.

### Torneos

Permite consultar los torneos publicados y utilizar diferentes filtros para encontrar torneos según las preferencias del usuario. Se puede filtrar por nombre del torneo, ubicación, nivel y fecha.

### Organizar torneo

Permite crear y disputar un torneo cargando sus datos y las parejas participantes.

Para crear un torneo se debe ingresar el nombre, la ubicación, una descripción opcional, las parejas participantes y el formato de competencia.

Una vez creado, el sistema genera automáticamente los partidos según el formato seleccionado. A medida que se cargan los resultados, se determinan las siguientes instancias y cruces del torneo.

## Formatos de torneo

MatchPoint permite organizar torneos utilizando diferentes modalidades:

| Formato | Descripción |
|---|---|
| **Eliminación directa** | La dupla que pierde queda eliminada y la ganadora avanza a la siguiente ronda. |
| **Todos contra todos** | Todas las duplas juegan entre sí y se genera una tabla de posiciones según los resultados. |
| **Fase de grupos + eliminación** | Las duplas se dividen en grupos, juegan una primera fase y luego continúan mediante cruces de eliminación. |
